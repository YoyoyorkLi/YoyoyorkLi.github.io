Inflation Pressure Index

What is this? This dashboard maps out the underlying factors that pressure and contribute to inflation. It is designed to help understand and analyze current economic conditions, rather than acting as a predictive crystal ball for future rates.

Methodology Documentation

Data Pipeline & Point-in-Time Reality

This index is built using ALFRED (ArchivaL Federal Reserve Economic Data) rather than standard FRED data. This is crucial because standard historical data is frequently revised years later, creating "look-ahead bias." By using ALFRED's initial-release vintage, this dashboard ensures that past index values reflect only the information that was publicly known at that exact moment in time.

How the Index is Constructed

  • Warmup Period: The script runs a rolling standard deviation to normalize the components, requiring a set "warmup" period (currently 20 quarters) to establish a baseline before generating scores.
  • Chained Composition: Rather than taking a simple average, the index uses "chain-linking." This means quarterly changes are measured only across data streams present in both the current and prior quarter. If a new dataset becomes available mid-sample, its arrival does not artificially skew or step the index up/down.
  • Publication Lag Handling: To prevent false forecasting, every data point is shifted forward to match its real-world publication date. The index refuses to map conditions using numbers that had not been published yet.

Components Tracked

The index actively maps several different pressures, including but not limited to:

  • Labor market tightness (Unemployment Rate, YoY Wage Growth)
  • Monetary policy posture (Fed Funds Rate)
  • Market volatility and expectations (VIX, 10-Year Breakeven, Michigan Inflation Expectations)
  • Commodity pressures (PPI All Commodities)
